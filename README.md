# PID Controller Board for an Industrial Furnace with On-Board AI Fault Diagnosis

Team **SemiBuhos** · B.Eng. in Semiconductor Engineering, Universidad de Sonora · AI-SED 2026

A PCB that controls an electric furnace with a PID loop, reads five type-K thermocouples, follows programmable ramp/soak profiles, and runs a decision-tree model on an 8-bit PIC microcontroller to detect and name faults (open heater, shorted MOSFET, stuck or drifting thermocouple) earlier than fixed safety rules.

## Hardware

- **Power and isolation:** 12 V input with fuse, reverse-polarity diode and TVS; B1209S isolated DC-DC converter and 7805 regulator for the 5 V logic; PC817 optocoupler driving an IRFZ44N MOSFET for the heater (up to 2.5 A). Logic and power grounds are joined only through the isolated converter and the optocoupler.
- **Sensing:** five MAX6675 thermocouple-to-digital converters on a shared SPI bus.
- **Control:** PIC16F1827 (Proteus model, 4K words) or PIC16F1847 (recommended for the board, 8K words), same 18-pin footprint.
- **Communication:** 9600 baud serial over a USB-TTL adapter.

## Firmware

- Fixed-point PID with derivative on measurement and conditional anti-windup; PWM at 244 Hz (10-bit) or a 2 s time-window output for solid-state relays.
- 4 profile slots × 9 ramp/soak segments in EEPROM with checksums.
- Six latched safety faults: over-temperature, loss of sensors, full power without temperature rise, process time exceeded, temperature rising with the heater off, auto-tuning out of range. Watchdog and reset-cause reporting.
- Sensor cross-validation (median outlier and stuck-reading detection).
- PIC16F1847 only: relay auto-tuning (Tyreus-Luyben), fault log, supply-voltage monitor and the AI fault diagnosis.

Memory with XC8 v4.00 (optimization level `s`): 3,881 / 4,096 words on the PIC16F1827, 6,621 / 8,192 on the PIC16F1847.

## AI fault diagnosis

- **Data:** the actual firmware, compiled for a PC, run against 900 simulated furnaces with random heating power, time constant, sensor lag, ambient temperature, sensor noise, zone gradients and profiles, with one fault injected at a random time. About 434,000 evaluation windows, split by run (630 training, 270 test).
- **Model:** CART decision tree, depth 7, 18 leaves, 10 integer features computed by the firmware every 10 s. Exported to C and evaluated on the microcontroller; a warning (`IA;n` on the serial port) is issued after 60 s of consistent predictions.
- **Results on the 270 test runs:**

| Fault | Rules: detected / median time | AI: detected / median time |
|---|---|---|
| Open heater | 96 % / 297 s | 96 % / 137 s |
| Shorted MOSFET/relay | 100 % / 130 s | 62 % / 98 s |
| Stuck thermocouple | 96 % / 789 s | 100 % / 141 s |
| Drifting thermocouple | 100 % / 372 s | 100 % / 129 s |

One false warning in 270 test runs. The firmware tree matches the Python model on all 455,297 evaluations (`ia/verificar.py`). The model was validated in simulation only; validation with a real furnace is pending.

## How to reproduce

Run the test bench (Windows with Visual Studio or gcc; also compiles for both PICs if XC8 is installed):

```bash
powershell -ExecutionPolicy Bypass -File banco\correr_banco.ps1
```

Regenerate the dataset, retrain the model and check firmware/model equivalence (Python 3, standard library only):

```bash
python ia/generar_datos.py 900 2026
python ia/entrenar.py
python ia/verificar.py
```

Build the firmware in MPLAB X with XC8, device PIC16F1827 or PIC16F1847, optimization level `s`. Define `SIMULAR_SENSORES=1` to run it in Proteus with the built-in furnace model.
